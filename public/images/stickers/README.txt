STICKERS DEL CHAT

Puedes reemplazar los emojis del chat agregando estos cinco archivos WebP:

- bien-hecho.webp
- listo.webp
- trabajando.webp
- recibido.webp
- urgente.webp

Recomendaciones:

- Tamano: 256 x 256 px.
- Fondo transparente.
- Formato WebP.
- Peso ideal: menos de 50 KB por imagen.

No es necesario modificar codigo ni la base de datos. El sistema detecta cada
archivo automaticamente y los mensajes solo guardan la clave corta del sticker.
